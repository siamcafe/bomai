## BOM AI คืออะไร

BOM AI คือโมเดลปัญญาประดิษฐ์ (AI) ภาษาไทยที่ตั้งใจพัฒนาเพื่อคนไทยโดยเฉพาะ
ทำงาน**บนเครื่องของคุณเอง** (Local AI) ผ่านโปรแกรมจัดการโมเดล Ollama
และหน้าจอสนทนา Open WebUI

จุดเด่นสำคัญ

- **เข้าใจภาษาไทยจริง** — อ่าน-เขียน-ตอบคำถามภาษาไทยได้เป็นธรรมชาติ
- **มองเห็นภาพ (Vision)** — ถ่ายรูปใบเสร็จ สลิป เอกสาร ป้าย แล้วถามได้ทันที (OCR อาจคลาดเคลื่อน ควรตรวจซ้ำ)
- **แชทโดยไม่ต้องต่อเน็ต** — คุยได้แม้ตัดอินเทอร์เน็ต (ค้นเว็บเป็นฟีเจอร์แยก ต้องต่อเน็ต และส่งคำค้นออกภายนอก)
- **ฟรีไม่มีค่าใช้จ่าย** — ไม่จำกัดจำนวนข้อความ (ในแอปมีแบนเนอร์พาร์ตเนอร์ XM)
- **ปุ่ม Thinking** — เปิดเพื่อคำตอบคุณภาพดีขึ้น (รอนานขึ้นหนึ่งรอบ ไม่เปิดเผย reasoning)

## ข้อควรรู้ (ซื่อสัตย์ ไม่ซ่อน)

- โมเดลขนาดเล็กในเครื่อง **อาจตอบผิด ไม่ครบ หรือวนซ้ำ** — ตรวจสอบข้อมูลสำคัญเสมอ
- **การติดตั้ง**ดาวน์โหลดส่วนประกอบจากอินเทอร์เน็ต · **การค้นเว็บ**ส่งคำค้นไปบริการภายนอก
- ตัวติดตั้ง**ไม่ได้ sign** (SmartScreen/Gatekeeper อาจเตือน) และจะสร้าง**บัญชีผู้ดูแลในเครื่อง** (ปิดการสมัครสาธารณะ)

## วิธีติดตั้ง

**Windows**
1. ดาวน์โหลด `Install-BOM-AI-Online.bat` จาก [bomai.app/download](https://bomai.app/download)
2. ดับเบิลคลิก — ตัวติดตั้งดึงส่วนประกอบเอง (~3 GB+, ต้องต่อเน็ตตอนติดตั้ง)
3. SmartScreen เตือน: "ข้อมูลเพิ่มเติม" → "เรียกใช้ต่อไป"

**macOS**
1. ดาวน์โหลด `install-bom-ai-mac.zip`
2. แตก ZIP ใน Finder → ดับเบิลคลิก `install-bom-ai-mac.command`
3. Gatekeeper เตือน: คลิกขวา → เปิด

**Linux**
```bash
curl --fail --location --proto '=https' -o install-bom-ai-linux.sh \
  https://bomai.app/dl/install-bom-ai-linux.sh
bash install-bom-ai-linux.sh
```

## วิธีใช้งาน

1. เปิดโปรแกรม **BOM AI** (รอจนหน้าจอสนทนาปรากฏ ครั้งแรกใช้เวลา ~1 นาที) แล้วล็อกอินด้วยบัญชีที่ตัวติดตั้งสร้างให้
2. พิมพ์คำถามภาษาไทยได้เลย เช่น "สรุปเอกสารนี้ให้หน่อย"
3. อยากให้ AI ดูภาพ กดปุ่มแนบรูป (📷) เช่น ใบเสร็จ สลิป แล้วถามได้
4. ต้องการข้อมูลล่าสุด เปิดปุ่มค้นเว็บก่อนถาม (ใช้อินเทอร์เน็ต)
5. ปิดโปรแกรมได้ทุกเมื่อ ประวัติแชทเก็บในเครื่องคุณเอง

## คำถามที่พบบ่อย (FAQ)

**ถาม: ต้องต่ออินเทอร์เน็ตไหม**
ตอบ: ต่อเน็ตตอนติดตั้ง และตอนใช้ค้นเว็บ ส่วนการคุยแชทธรรมดาทำงานในเครื่อง ไม่ต้องต่อเน็ต

**ถาม: ข้อมูล/ข้อความที่แชทเก็บไว้ที่ไหน**
ตอบ: เก็บในเครื่องคุณเอง ลบทิ้งได้ทุกเมื่อ (ยกเว้นคำค้นหาเว็บที่ส่งไปบริการค้นหาภายนอกขณะใช้ฟีเจอร์ค้นเว็บ)

**ถาม: ฟรีจริงไหม**
ตอบ: ฟรี ไม่มีค่าใช้จ่าย ไม่จำกัดข้อความ โค้ดเปิด ([GitHub](https://github.com/siamcafe/bomai)) — ในแอปมีแบนเนอร์พาร์ตเนอร์ XM

**ถาม: เครื่องผมเก่ารับไหวไหม**
ตอบ: RAM 8 GB ขึ้นไปใช้ Light ได้ ส่วน Pro ต้องมี GPU VRAM 12 GB+ ต่ำกว่านั้นขออภัยด้วย

**ถาม: ทำไมบางคำถามตอบผิด**
ตอบ: โมเดลขนาดเล็กมีข้อจำกัด เช่น ข้อเท็จจริง วันที่ ตัวเลข ควรตรวจสอบซ้ำ และ BOM AI **ไม่สามารถสร้างภาพ** ได้ (อ่านภาพเท่านั้น)
